    Search syntax

    foo barFiles containing both foo and bar. Each term is a regular expression.
    "foo(bar"Literal text (invalid regular expressions are also searched literally).
    foo OR barFiles containing either term (AND is implied between terms).
    -foo, NOT fooExclude files containing foo.
    (a OR b) -file:testGroup with parentheses. file: and lang: work inside groups too.
    file:\.cc$File path matches a regular expression (also f:, -file:).
    file:src/**/*.ktPath glob: * within a folder, ** across folders; a leading / anchors at the repository root.
    lang:javaLanguage: c, c++, java, kotlin, go, py, rust, ts, bp, aidl, … (also -lang:).
    repo:aospRepository name (also r:, -repo:).
    sym:ActivityDefinitions of a symbol.
    class:.*Impl$Types whose names match a regular expression; function: for functions and methods, symbol: for any kind. Qualified names work: func:Rect::intersect.
    -is:testExclude test files; also is:generated and is:vendored (third-party code). Without -, search only them.
    usage:fooOnly outside comments and strings. comment:foo and string:foo match only inside them.
    case:yesCase-sensitive. Search is case-insensitive by default; case:auto makes terms with upper-case letters case-sensitive.

    Code browsing

    Click an identifierShow its definitions and references.
    Ctrl/⌘+clickJump straight to the definition.
    Hover an identifierShow its definition and documentation (i does the same for a selected identifier).
    Click a line numberLink to that line; Shift+click selects a range.

    Keyboard shortcuts

    /Focus the search box
    j / kNext / previous search result; Enter or o opens it
    fFind text in the current file
    n / NNext / previous match in file
    yCopy a permalink to this file (pinned to the current commit)
    bToggle blame (who last changed each line)
    hShow the file's git history
    oShow and filter the file outline
    tToggle the sidebar
    EscClose the bottom panel
    ?Show this help
